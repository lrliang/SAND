# SAND 方法论参考文档索引

> **SAND**（Scaled AI-Native Development）是一套面向软件组织 AI 原生转型的系统方法论。

本目录包含 SAND 方法论的原始概念设计和完整设计过程记录。


## 目录结构

```
ref_docs/
├── 原始概念/          ← SAND 方法论的两个基础版本
├── 设计过程/          ← 从概念到完整框架的迭代深化过程
└── index.md           ← 本文件
```
