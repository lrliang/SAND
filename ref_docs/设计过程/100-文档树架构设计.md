# 文档树架构设计

技术焦点：将76个DNA洞见 + 6个空白转化为 docs/ 目录下的具体树形文档结构
能量：中——结构化、收敛性思维

设计原则（在开始画树之前先对齐）：

  1. 每个节点 = 一个 .md 文件或一个文件夹
  2. 树的深度不超过3层（太深则难以导航）
  3. 每个文件有明确的"单一职责"——一个文件回答一个问题
  4. 遵循"方法论即代码"理念——理论文档和可执行模板/工件并存
  5. 支持渐进式阅读——新人从根节点的总览开始，按需深入

---
