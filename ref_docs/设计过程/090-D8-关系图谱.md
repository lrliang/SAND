[Framework DNA #71]：人-模型关系的深化——信任度模型
Concept：人和 AI 模型之间的核心关系是信任度，它不是静态的，而是动态校准的——
  - 初始信任度：基于模型的基准能力评估（如 SWE-Bench 成绩）设定
  - 场景信任度：同一模型在不同任务类型中的信任度不同（编码能力 vs 业务理解能力）
  - 累积信任度：通过实际使用中的审查结果持续校准
  - 衰减机制：模型更新后信任度重置到基准，需要重新累积

这直接驱动 HIP 的动态调整——信任度高的模型在熟悉的场景中获得 HIP-1 级别，信任度低或场景新颖时自动升级到 HIP-2/3

[Framework DNA #73]：模型-工具关系——AI 能力栈
Concept：AI 模型不是直接作用于项目的，它通过工具来执行——

AI 模型能力
│
├─ 代码生成能力 ──→ 通过 IDE集成工具 ──→ 作用于 Build阶段
├─ 分析推理能力 ──→ 通过 Agent编排平台 ──→ 作用于 Orchestrate/Validate
├─ 自然语言能力 ──→ 通过 意图管理工具 ──→ 作用于 Intent（意图澄清）
└─ 模式识别能力 ──→ 通过 度量分析工具 ──→ 作用于 Learn（模式提炼）

工具是模型能力的"放大器"和"约束器"——好的工具放大模型的优势、约束模型的风险
