# Step 2: 资产分类与趋势分析

## MANDATORY EXECUTION RULES (READ FIRST):

1. 读完整个步骤文件后再执行——不要边读边做
2. 按编号顺序执行每个子节——不跳步
3. 遇到不确定性时请求人类确认——不猜测用户意图
4. 每个子节完成后向用户汇报进度——保持透明
5. 失败时快速报错并说明原因——不静默降级或继续

## YOUR TASK:

基于 Step 1 产出的资产候选列表，按 5 类 AI 资产标准进行分类，并分析飞轮指标历史趋势。

## EXECUTION SEQUENCE:

### §1 加载 Step 1 产出

从最新的复盘日志中读取元数据和资产候选列表：

1. 扫描 `.sand/retrospectives/` 目录，按文件名日期和序号排序，找到最新的 `{YYYYMMDD}_retro_{seq}.md`
2. 从「元数据」节读取 `复盘类型` 字段（micro / macro / deep）
3. **如果 `retro_type` = micro：**
   - 输出：`ℹ️ 微循环复盘不包含资产分类和入库建议。复盘已在 Step 1 完成。`
   - 正常结束——不执行后续步骤，不视为错误
4. 从该文件的「议题 5: 资产化提名」节提取 `asset_candidates` YAML 块
5. 解析候选列表，统计总候选数

**如果候选列表为空或文件不存在（非 micro 类型）：**
- 输出：`⚠️ 未找到资产候选列表。可能原因：复盘日志不存在，或议题 5 未产出候选。`
- 提示用户选择：`[1] 返回运行 Step 1 宏循环复盘 / [2] 手动输入候选 / [3] 跳过分类直接结束`
- 如用户选择 [3]：正常结束——不执行后续步骤

**输出加载摘要：**

```
📂 已加载复盘日志：{filename}
📊 复盘类型：{retro_type}
📋 资产候选总数：{count}
```

### §2 5 类资产分类

将每个候选按 `asset_type` 字段分组到 5 类中：

| type_code | 资产类型 | asset_type 值 |
|-----------|---------|---------------|
| CTX | 上下文资产 | context |
| INT | 意图模式 | intent_pattern |
| ORC | 编排配方 | orchestration_recipe |
| VAL | 验证规则 | validation_rule |
| FAI | 失败案例 | failure_case |

**展示分类结果：**

```
📊 资产分类结果

| 类型 | 候选数 | 高频 | 中频 | 低频 | 平均置信度 |
|------|--------|------|------|------|-----------|
| CTX 上下文资产    | {n} | {h} | {m} | {l} | {avg} |
| INT 意图模式      | {n} | {h} | {m} | {l} | {avg} |
| ORC 编排配方      | {n} | {h} | {m} | {l} | {avg} |
| VAL 验证规则      | {n} | {h} | {m} | {l} | {avg} |

是否需要调整任何候选的分类？[Y] 是 / [N] 继续
```

如用户要求调整：逐个展示有疑议的候选，允许用户重新指定 `asset_type`。

### §3 历史趋势分析

扫描 `.sand/retrospectives/` 中所有历史复盘日志，提取每轮的飞轮指标快照：

1. 列出所有 `{YYYYMMDD}_retro_{seq}.md` 文件，按日期排序
2. 从每个文件的「飞轮指标快照」节提取三指标数值
3. 如仅有 1 轮数据（当前复盘），标注"首轮复盘，无趋势数据"

**展示趋势表（如有多轮数据）：**

```
📈 飞轮指标趋势

| 日期 | 资产复用率 | 意图首通率 | 循环压缩率 | 健康度判断 |
|------|-----------|-----------|-----------|-----------|
| {date_1} | {reuse_rate_1}% | {first_pass_rate_1}% | {compression_rate_1} | {judgment_1} |
| {date_2} | {reuse_rate_2}% | {first_pass_rate_2}% | {compression_rate_2} | {judgment_2} |
| ... | ... | ... | ... | ... |

趋势方向：
- 资产复用率：{↑/↓/→} ({delta})
- 意图首通率：{↑/↓/→} ({delta})
- 循环压缩率：{↑/↓/→} ({delta})
```

**飞轮健康度联动判断**（参见 flywheel-metrics.md）：

| 场景 | 复用率 | 首通率 | 压缩率 | 诊断 |
|------|--------|--------|--------|------|
| 飞轮加速 | ↑ | ↑ | < 1.0 | 理想状态 |
| 空转 | ↑ | → | ≈ 1.0 | 检查资产质量 |
| 虚假加速 | → | → | < 1.0 | 可能走捷径 |
| 资产过时 | ↓ | ↓ | > 1.0 | 资产库需刷新 |
| 单维突破 | ↑ | ↑ | > 1.0 | 资产和质量改善但任务复杂度上升——正常 |

### §4 生成分析摘要

综合分类结果和趋势数据，生成结构化分析摘要：

```
📋 分析摘要

**资产分类统计：**
- 总候选数：{total}
- 按类型分布：CTX({n}) / INT({n}) / ORC({n}) / VAL({n}) / FAI({n})
- 高频候选占比：{high_pct}%
- 平均置信度：{avg_confidence}

**飞轮趋势（如有）：**
- 整体判断：{飞轮加速 / 空转 / 虚假加速 / 资产过时 / 单维突破 / 首轮无数据}
- 关键发现：{1-3 条要点}

**改进建议：**
- {基于分类和趋势的 1-3 条建议}
```

将分析摘要传递给 Step 3。
