# 组织模型

SAND 的组织模型围绕"人-AI协作的颗粒度"设计四个层级，每层有自己的角色、仪式、度量和 SDC 运转节奏。

## 目录

- [four-layer-model.md](./four-layer-model.md) — 四层分级模型（Individual → Pod → Product → Organization）
- [roles/](./roles/) — 角色体系（4种核心角色）
- [atomic-capabilities.md](./atomic-capabilities.md) — 5种原子能力模型
- [pod-formation.md](./pod-formation.md) — Pod 组建与解散原则
- [ceremonies.md](./ceremonies.md) — 仪式/事件体系（7种仪式）
- [career-paths.md](./career-paths.md) — 角色成长路径 `[GAP-2: 待开发]`

## 四层概览

| 层级 | 核心单元 | 关键角色 | SDC节奏 |
|------|---------|---------|---------|
| L1 个体 | 1 FDE+ + N Agent | FDE+ | 微型循环（分钟级） |
| L2 团队 | Mission Pod（3-7人） | FDE+ + AI编排师 + 问题域负责人 | 标准循环（天/周级） |
| L3 产品 | 多Pod + 产品域负责人 | 产品域负责人 | 战略循环（月/季度级） |
| L4 组织 | 整个组织 | AI转型负责人 + 变革催化师 | 治理循环（季度/年度级） |

## 四种核心角色

| 角色 | 核心使命 | 主导SDC阶段 |
|------|---------|------------|
| [FDE+](./roles/fde-plus.md) | 端到端交付问题解决方案 | Build, Validate |
| [AI编排师](./roles/ai-orchestrator.md) | 设计最优人-AI协作架构 | Orchestrate |
| [问题域负责人](./roles/problem-domain-lead.md) | 定义正确的问题和成功标准 | Intent, Assess |
| [变革催化师](./roles/change-catalyst.md) | 推动组织AI原生能力成长 | Learn |
