# 角色体系

SAND 定义 4 种核心角色。关键原则：角色不是职位，是责任域——一个人可以同时承担多个角色，角色随问题域流动。

## 角色清单

- [fde-plus.md](./fde-plus.md) — FDE+（全栈交付工程师）
- [ai-orchestrator.md](./ai-orchestrator.md) — AI 编排师
- [problem-domain-lead.md](./problem-domain-lead.md) — 问题域负责人
- [change-catalyst.md](./change-catalyst.md) — 变革催化师

## 不相容分离原则

意图定义者和意图验证者不能是同一个人——防止"自说自话"。这类似于财务审计中"不相容职务分离"原则。

## 角色-SDC 阶段映射

| 角色 | 主导阶段 | 参与阶段 |
|------|---------|---------|
| FDE+ | Build, Validate | 全部 |
| AI编排师 | Orchestrate | Build, Learn |
| 问题域负责人 | Intent, Assess | Validate, Operate |
| 变革催化师 | Learn | Assess, 全部（观察） |
