# 治理中心轴（Governance）

治理贯穿 SDC 的所有 7 个阶段，不是某个阶段的工作。它是 SAND 方法循环的"旋转轴心"——持续运转的底层机制。

## 四根支柱

- [decision-governance.md](./decision-governance.md) — 决策治理：关键决策点的人类最终确认权
- [compliance-governance.md](./compliance-governance.md) — 合规治理：AI使用边界、数据安全、许可证合规
- [quality-governance.md](./quality-governance.md) — 质量治理：AI产出的审查覆盖率、质量门禁标准
- [audit-governance.md](./audit-governance.md) — 审计治理：所有AI参与的决策和产出留下可追溯证据链

## 核心原则

> 治理不随阶段切换而改变，而是持续运转的底层机制。
> 每次 AI 参与决策或生成产物时，必须留下可追溯的结构化证据链。
