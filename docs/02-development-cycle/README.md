# SDC — SAND Development Cycle

SDC 是 SAND 框架的核心方法引擎，一个 7 阶段闭环方法循环 + 治理中心轴。

## 全景图

```
           ┌──────────────────────────────────────┐
           │          Governance（治理中心轴）        │
           │   决策治理 · 合规治理 · 质量治理 · 审计治理   │
           └──────────────────────────────────────┘

 Assess ──→ Intent ──→ Orchestrate ──→ Build ──→ Validate ──→ Operate ──→ Learn
   ▲                                     ↑          │                       │
   │                                     │          │ 打回                  │
   │                                     └──────────┘ Build                 │
   │                         ↑                      │                       │
   │                         │                      │ 重定向                 │
   │                         └──────────────────────┘ Intent                │
   │                                                                        │
   └────────────────────────── 飞轮闭环 ────────────────────────────────────┘
                        资产反馈 + 校准信号
```

## 非均匀节奏

| 阶段 | 典型时长 | 特点 |
|------|---------|------|
| Assess | 首次2-4周 / 循环校准1-2天 | 双模运行 |
| Intent | 数小时到数天 | 取决于意图复杂度 |
| Orchestrate | 数小时（成熟团队可分钟级） | 可复用编排配方 |
| Build | 脉冲式（AI 10-30min + 人类审查30-60min） | 速度悖论 |
| Validate | 三通道并行，数小时到1天 | 并行加速 |
| Operate | 持续运行 | 信号持续采集 |
| Learn | 每轮循环结束，1-2天 | 资产化而非行动项 |
