# 意图阶段（Intent）

> "我们要解决什么问题？成功长什么样？"

Intent 是 SDC 循环中最关键的输入阶段。意图定义的质量决定了整个循环的上限——AI 会忠实地、高效地、大规模地执行一个错误的意图。

- [execution-contract.md](./execution-contract.md) — 执行契约标准（must_pass/should_pass/must_not_violate）
- [intent-taxonomy.md](./intent-taxonomy.md) — 5种意图类型学
- [decomposition-patterns.md](./decomposition-patterns.md) — 3种意图分解模式

## 核心产出工件

- 《意图声明》（Intent Statement）
- 《执行契约》（Execution Contract）
- 《约束上下文》（Constraint Context）
- 《投资假设》（Investment Hypothesis）

## 关键原则

意图声明的质量决定了整个循环的上限。AI 的高效率反而使"意图错误"的代价成倍增加。
