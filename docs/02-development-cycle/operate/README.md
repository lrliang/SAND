## 三级运营自动化

| 级别 | AI 行为 | 人类行为 |
|------|--------|---------|
| OPS-1 | 自动检测+自动修复 | 事后审阅日志 |
| OPS-2 | 分析根因+生成方案 | 审查批准执行 |
| OPS-3 | 提供数据和分析 | 独立判断决策 |
