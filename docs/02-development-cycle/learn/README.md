# 学习阶段（Learn）

> "我们学到了什么？什么可以资产化？"

Learn 是 SDC 飞轮的动力源。它的核心使命不是"回顾"而是"资产化"——产出可机器消费的 AI 资产，注入下一轮循环的上下文中。

## 5 类 AI 资产

| 类型 | 来源阶段 | 消费阶段 |
|------|---------|---------|
| 上下文资产 | 全循环 | Orchestrate |
| 意图模式 | Intent + Validate | Intent |

## 飞轮核心机制

Learn 产出的不是"行动项"，而是"可执行资产"——直接反馈到下一轮 Assess（降低评估成本）和 Orchestrate（提高编排效率），形成越转越快的飞轮。
