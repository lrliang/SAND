# 编排阶段（Orchestrate）

> "谁来做？怎么协作？AI 拓扑怎么设计？"

Orchestrate 是 SAND 最独特的阶段——在传统框架中完全不存在。它是 AI 原生开发独有的：你需要决定"哪些 AI 做什么、人在哪里介入、上下文怎么流转"。

## 5 个子过程

- [context-engineering.md](./context-engineering.md) — O1：上下文工程（上下文金字塔、质量评估模型）
- [agent-selection.md](./agent-selection.md) — O2：Agent 选型决策框架（能力卡标准）
- [topology-patterns.md](./topology-patterns.md) — O3：4种标准拓扑模式（Solo/Pipeline/Swarm/Hierarchy）
- [human-intervention.md](./human-intervention.md) — O4：三级人类介入模型（HIP-1/2/3 + 动态调整）
- [failure-modes.md](./failure-modes.md) — O5：AI 失败模式分类学

## 核心产出工件

- 《编排方案》（Orchestration Plan）
- 《Agent 拓扑图》
- 《上下文策略》
- 《人类介入点定义》

## 为什么 Orchestrate 是 SAND 的核心创新

一个优秀的编排方案可以让 AI 杠杆率达到 10x，一个糟糕的编排可能让 AI 成为阻碍。这是"AI原生工程"最核心的能力。
