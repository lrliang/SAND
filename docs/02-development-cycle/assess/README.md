# 评估阶段（Assess）

> "我们在哪里？我们准备好了吗？"

评估是 SDC 循环的起点和终点。它有两种运行模式：首次诊断模式（全面组织评估，2-4周）和循环校准模式（基于上轮Learn的快速检查，1-2天）。

## 目录

- [maturity-framework.md](./maturity-framework.md) — 7维度成熟度评估框架
- [gap-analysis.md](./gap-analysis.md) — 差距分析与转型路径（雷达图诊断）
- [assess-tools.md](./assess-tools.md) — 可执行评估工具说明

## 角色分工

| 角色 | 职责 |
|------|------|
| 变革催化师 | 组织评估活动，引导诊断 |
