# SAND — 规模化AI驱动开发方法

**Scaled AI-Native Development Methodology**

---

## 框架定位

SAND 是一套面向软件开发组织 AI 原生转型的系统方法论框架。它融合三大来源的结构基因，形成一个全新的框架物种——**可执行的全景方法论（Executable Panoramic Methodology）**：

- **SAFe 的全景图可视化**：一张图看到所有层级、角色、流程和工件的关系
- **TOGAF 的标准化方法循环**：每个阶段有明确的输入、步骤、输出和治理机制
- **bmad-method 的方法论即代码**：理论文档与可执行模板/工作流并存

## 核心引擎：SDC（SAND Development Cycle）

SAND 的核心是一个 7 阶段闭环方法循环 + 治理中心轴：

```
Assess → Intent → Orchestrate → Build → Validate → Operate → Learn
                         ↑                                        │
                         └──────── 飞轮闭环（资产反馈）─────────────┘

                    Governance（治理中心轴）贯穿全程
```

## 三个视角

| 视角 | 回答的问题 | 对应内容 |
|------|-----------|---------|
| **全景图层（What）** | SAND 包含什么？各部分如何关联？ | 组织模型、角色、工件、仪式、度量 |
| **方法循环层（How）** | 怎么做？每一步的标准流程是什么？ | SDC 7阶段 + 治理中心轴 |
| **可执行层（Run）** | 拿起来就能用的工具是什么？ | 模板库、检查清单、评估工具 |

## 四层组织模型

| 层级 | 核心单元 | SDC 节奏 |
|------|---------|---------|
| **L1 个体层** | 1个 FDE+ + N个 AI Agent | 微型循环（分钟级） |
| **L2 团队层** | Mission Pod（3-7人） | 标准循环（天/周级） |
| **L3 产品层** | 多个 Pod + 产品域负责人 | 战略循环（月/季度级） |
| **L4 组织层** | 整个组织 + AI 转型领导层 | 治理循环（季度/年度级） |

SAND 帮助组织实现：每个人都能正确、高效、不浪费地使用 AI。
